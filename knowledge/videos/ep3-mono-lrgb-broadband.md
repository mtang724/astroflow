## 线性阶段：和彩机不同的地方

| 环节 | 做法 | 依据（时间） |
|---|---|---|
| 准备 | 四张图自动拉伸看一下（单通道，STF 锁链无所谓）；**按通道重命名** L/R/G/B，否则分不清 | 14:14–15:38 |
| 星点对齐 | **StarAlignment**：参考图 = L（View），目标 = R/G/B（Add Views），其余默认（Projective，Register/Match）。四个通道可能不是同一次叠加的，不对齐合成会错位 | 15:41–17:45 |
| 裁切 | 对齐后边缘有黑边：找黑边最大的那张，DynamicCrop 框在完全重合的区域，**拖出一个实例**再应用，四张用同一个裁切 | 17:47–18:56 |
| 背景提取 | 每个通道单独做。小星系（占画面很小）用 **SetiAstro → Automatic DBE**（V1.6，默认：50 条下降路径、容差 2.0、多项式 1 阶、Subtract），适合目标只占画面一小块的情况 | 18:59–20:27 |
| 通道合成 | **ChannelCombination**：RGB 色彩空间，R/G/B 依次选对应图像 → 一张三通道彩色图；合成后发绿是 STF 锁链的缘故 | 20:29–21:58 |
| 色彩校准（BNCC） | BN：上限 **0.01**；CC：白参考 **框住整个星系**（428×702 的框），**取消 Structure Detection**，背景参考同一背景框、上限 **0.0015** | 22:02–22:57 |
| 色彩校准（SPCC） | 用 M81 演示：先 ImageSolver 板解析；QE 曲线选传感器（IMX571 → "Sony IMX411/455/461/533/571"）；**R/G/B 滤镜选自己用的那套**（Antlia V Pro Series R/G/B）；不开 Narrowband；背景参考框一块背景。M51 用的图谱滤镜不在 SPCC 列表里 → 只能 BNCC（可以自己导入滤镜曲线，作者没研究） | 22:57–25:59 |
| RGB 的后续 | **RGB 不做 BXT、不做降噪**（多数人只对 L 做反卷积，效果经 L 带到彩色上）；直接 **EZ Soft Stretch**，中值调高到 **0.24** | 26:03–27:12 |
| L 通道 | ADBE 去梯度（左暗右亮）→ 检查模型 → 星系旁还有一点暗 → **再做一次 GC（默认）**。去背景可以重复做，直到背景平整为止，但不能把图做坏 | 27:12–28:03 |
| L：反卷积 | 单通道不需要色彩校准 → 直接 **BXT（默认）**；星点和旋臂明显变清楚 | 28:03–28:45 |
| L：线性降噪 | NXT AI3，Intensity/color separation ✓；**彩噪 0（单通道不需要）**，明度 **0.25**（信噪比高） | 28:46–29:19 |
| 为什么要 L | L 滤镜同时通过 R、G、B 三个波段，同样的时间里信噪比比单个颜色通道高得多；颜色来自 RGB，细节和信噪比来自 L | 29:36–31:24 |
| L 的拉伸 | 关键是亮度和彩色图一致：从拉伸后的 RGB 里提一张亮度作参照，手动调 STF 让 L 和它亮度差不多，再 STF→HT 应用（本次：shadows 0.0159，midtones 0.0018）。L 拍得久，噪声明显比 RGB 提出来的亮度少 | 31:26–33:41 |
| LRGB 合成 | **LRGBCombination**：只勾 L（取消 R/G/B），L 选 L 图，拖到 RGB 图上应用。合成后噪声明显减少。L 拉得不好会把颜色冲淡 → **Saturation 往左拉**（0.5 → 0.35 太浓 → 最后 **0.40**），Lightness 保持 0.5。BXT 的效果随 L 带进彩色图 | 33:43–36:00 |

## 非线性阶段（36:03 起）：和彩色相机的流程相同

| 环节 | 本期做法 | 时间 |
|---|---|---|
| 去星 | SXT | 36:14–36:50 |
| 结构强化 | RangeSelection 蒙版框住星系（Lower **0.23**，Upper 1，Fuzziness 0，Smoothness **65**，Lightness ✓）；LHE **Kernel 512**、Contrast Limit **1.3**、Amount **1.0**；注意 LHE 可能在星系边上出黑边 → 调内核半径 | 36:50–37:45 |
| 调色 | L 蒙版（先用 HT 切掉暗部，背景别被选进去）→ CT 调饱和度和 RGB | 37:47–38:35 |
| 压亮度 | 图有点过曝，是因为 L 拉伸得不到位（做太快了）→ HT midtones **0.608** 压回去，再补一点颜色 | 38:37–39:40 |
| 非线性降噪 | NXT：彩噪 **0.90**（彩噪还挺多），明度 **0.15** | 39:47–40:12 |
| 锐化 | USM 0.8 明显过度，0.57 也偏多 → **不锐化**：星系小、分辨率有限，锐化后显得假 | 40:13–41:06 |
| 对比度 | HT 黑点 **0.0304**（背景还有点亮） | 41:07–41:20 |
| 星点 | 随便拉点饱和度，PixelMath 贴回 | 41:21–41:42 |

视频里非线性阶段做得比较快，实际处理时应按目标和审美细调。

## 自动化实现（`mono_lrgb_*` 配方）
- 起点：WBPP 对黑白相机按滤镜分别叠加（`masterLight_..._FILTER-L_mono.xisf` 等），`astroflow/mono.py` 按文件名认出 L/R/G/B（Lum、Red、ZWO G 之类的名字也认）。有 R、G、B 就用黑白配方；没有 L 时用 R/G/B 的平均当 L。
- `channels` 阶段（一次 PixInsight）：`align_channels`（StarAlignment，参考 L，目标作为 View，和视频一样；直接在视图上执行 StarAlignment 不会改动图像）→ `crop_common`（四个通道都有数据的区域，自动找边）→ 板解析 L（裁切会删掉解析结果，所以裁完再解）→ 定位目标 → 每个通道各自去背景（星系：`dbe_auto` 避开星系，代替 SetiAstro 的 ADBE 脚本，因为脚本不一定装了；星云：GC）→ `combine_rgb`（R/G/B 合成彩色图，并带上 L 的解析结果）。保存 `10_rgb` 和 `10_lum`。
- `color`：BNCC（星系白参考取星系本体、关结构检测）。SPCC 需要所用滤镜的曲线，滤镜因人而异，默认不用。
- `lum`：星系先补一次 GC，再 BXT、NXT（0.25，彩噪 0）。
- `stretch`：RGB 用 EZ Soft Stretch 0.24；L 用 EZ Soft Stretch，目标中值 = 拉伸后 RGB 的 CIE L* 中值（`matchLightnessOf`，代替视频里的目测匹配，所以不需要视频里后来那一步压亮度的 HT）；`lrgb`：只用 L，Lightness 0.5，Saturation 0.40。
- 之后同彩机：星系用本期的参数（LHE 范围蒙版 0.23/65，Amount 1.0；NXT 0.15/0.90；USM 默认关闭，可在参数里打开），星云沿用第1期。
- 星系的调色和对比度按视频成品校准：饱和度 0.75 两遍（L 蒙版），HT 黑点让天空落到 0.10（`shadows: "sky"`）。视频成品（41:54 截图）星系平均饱和度 0.107、天空 0.106；配方跑出来 0.107、0.102。只做一遍 0.72、黑点按裁剪比例时只有 0.046 和 0.23（发灰）。
- 测试：用教程的 M51 四通道主帧跑通全流程（8 个阶段约 3.5 分钟）；另把 R 平移 25×15 px、旋转 0.4° 检验对齐和裁切（对齐后偏移 0，裁掉配准空边）。
- 踩过的坑：StarAlignment 直接 `executeOn(view)` 不改图像（要把窗口作为 targets 全局执行）；LRGBCombination 的 `channels` 行顺序是 R、G、B、L（对话框里 L 在最上面），写错会把 L 写进红通道，星系变粉红。
