# 各阶段的检查标准（来自第1/2期视频 + 指标经验）

agent 每跑完一个阶段：先看数字，再用 `look` 看图（必要时带参考图），按下表判断是否重跑。

## linear（背景提取 + 色彩校准 + BXT + 线性降噪）
- **背景模型**（`10_gc_model` 或 dbe 的 modelRange）：只能是平滑的大尺度梯度（横向、对角、暗角）。如果模型里出现天体形状（星系/星云轮廓）或局部亮块 → GC 把天体当成背景了（视频 ep2 M31）→ 改用 `dbe_auto`（星系）或调 GC 参数 / ABE。
- 去梯度后（`10a_after_cc`）四角与中心背景亮度一致；`metrics.tile_spread_p90_p10` 主要由天体贡献而不是边角。
- **色彩**：背景中性灰（`background_cast` R/G、B/G 在 0.95–1.05）；大多数星点接近白色（有黄/蓝星正常）；颜色符合常理：
  - 发射星云（Ha）宽带下呈粉红/洋红/红色，反射星云蓝色，尘埃棕色；行星状星云 OIII 青绿 + Ha 红；
  - 星系核心偏暖黄，旋臂偏蓝，HII 区粉红点。
  - SPCC 优先；`color_calibration` 的 info.method 若为 bncc 说明 SPCC 失败（需在报告写明）。BNCC 若有“一层黄雾”是常见问题。
- BXT 后星点变圆变小、边角拉线减轻；不应出现黑环/硬边（严重时 `sharpen_stars` 降到 0.3 或 `correct_only`）。
- 线性降噪后仍保留细节、不涂抹（宁轻勿重）。

## stretch
- 拉伸后中值（`lum_median`）约 0.15–0.25；核心不能大面积 255（`clip_high_pct` 很小）；背景没有被切黑（`clip_low_pct`≈0）。
- 星系核心过曝 → 目标中值降低（0.15–0.18）或后面用 `hdr`。

## stars（SXT）
- `30_starless` 无明显星点残留/黑洞；亮星光晕残留属正常（视频：参宿一的光晕不处理）。
- `31_stars` 只有星点，没有星云结构。

## starless（非线性：LHE、饱和度、对比度、降噪、锐化）
- 结构强化自然，不出现亮暗晕圈、背景结块；满屏星云可不打蒙版，星系用范围蒙版只作用于星系。
- **饱和度（用户反馈：第一版普遍偏淡）**：以 `compare_with_references` 返回的 `subject_chroma.ratio`（主体 Lab 色度 / peer 中位数）为准，目标 **0.8–1.2**。低于 0.8 就提高 `sat.boost`（0.72→0.8）或 `passes`（1→2），并检查 `maskMidtones`（默认 0.3，越小蒙版越亮、作用越强）；彩色噪声交给 NXT 的 `denoise_color`，**不要以积分时间短为理由接受明显偏淡的颜色**。高于 1.3 或出现荧光感、彩色斑块才算过度。旧指标 `signal_saturation_mean` 受白色核心和星点影响，不作为饱和度依据。
- 对比度：背景不应过黑丢失暗部（`background_level` 与参考相近），主体有层次；暗星云不能比主体更显眼（视频 ep1 18:15）。
- 降噪：无彩色噪点，暗区不“塑料感”；锐化不过头（无白边、噪声颗粒）。

## stars_color
- 星色有冷暖区分但不“炸”（边缘彩色光圈）；无绿色星（SCNR 去绿）。72ED 双分离色差大，饱和度要克制。

## combine / 成品
- 星点不过多过亮抢主体（星点太强可 `starsAmount` 0.8–0.9）；整体与参考作品相比：主体颜色、背景亮度、对比度、星点大小。
- 最终必须再看一次 `subject_chroma.ratio`（星点合并会略微冲淡颜色），不足 0.8 回到 starless 阶段加饱和度。
- 宽带彩机不要追求窄带 SHO/HOO 配色。
- 一晚的数据（1–2 h）达不到参考作品的深度是正常的，报告里说明差距来自积分时间还是处理。
