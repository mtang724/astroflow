# astroflow 0.2.0：第一个桌面版

**拍完一晚，剩下的交给它。** 导入拍摄数据，自动配好暗场、偏置、平场，用 WBPP 叠加，按目标类型的配方在 PixInsight 里出图；还可以让 AI 助手对照同目标的高赞作品判断效果、调整参数。

![astroflow](https://raw.githubusercontent.com/mtang724/astroflow/main/docs/images/overview.png)

## 下载

| 系统 | 文件 | 状态 |
|---|---|---|
| Windows 10 / 11（64 位） | `astroflow-0.2.0-setup.exe` | 已测试 |
| macOS（Apple 芯片） | `astroflow-0.2.0-arm64.dmg` | 预览版，尚未在真机上完整测试 |

安装方法和完整用法见[使用说明](https://github.com/mtang724/astroflow/blob/main/docs/user-guide.md)。

## 需要准备

- **PixInsight** 1.9 或更新（自带 WBPP）。astroflow 负责驱动它，不能替代它。
- **RC Astro**：BlurXTerminator、NoiseXTerminator、StarXTerminator。
- **Gaia DR3/SP 数据库**：在 PixInsight 里配好，SPCC 色彩校准要用。
- **拍摄数据**：FITS 格式。现有配方针对彩色相机（OSC，包括单反）。
- **AI 模型**（可选）：DeepSeek、OpenAI 或任何 OpenAI 兼容接口，也可以用 Ollama / LM Studio 本地模型。

## 功能

- **导入不用操心**
  - 认得 ASIAIR、NINA、SharpCap、Ekos 等软件的导出、存储卡，或者已经分好 Light/Dark/Bias/Flat 的文件夹。
  - 按每张图的文件头认帧类型，按目标和日期整理。
  - 暗场、偏置、平场先用同一批拍的，缺的再从校准帧库找。单反（ISO、无温度）和黑白相机的滤镜都能匹配。
  - 导入前先看计划：缺什么写得清清楚楚。
  - 补拍的暗场导入后，会自动补给缺它的目标。
- **一键出图**
  - WBPP 校准、配准、叠加。
  - 四个配方：宽带星云、星系、多波段星云、彗星，配方参数整理自 PixInsight 进阶教程。
  - 每个配方六个阶段，每个目标一般 3–7 分钟出成品（PNG / JPG / 16 位 TIF）。
- **按自己的口味调**：每一步的参数都能改，改完只重跑那一个阶段；改过的参数会记住，以后每次运行都用。
- **AI 助手**
  - 一句话说想要的效果（“背景再暗一点”“星云颜色更明显”）。
  - 它会看图、和高赞作品比较、调参重跑、写报告，每一步都看得见。
  - 可以随时停止。
- **难例也能做**：穿云拍的彗星，只有几帧、曝光长短不一。按星点和彗核分别叠加，云和卫星轨迹自动剔除。
- **看图和对比**：各阶段预览、成品、参考作品，可以缩放，也可以拖动滑块对比两张图。
- **一次一个 PixInsight**：任务排队运行，实时日志，随时停止；关闭应用时不会在后台留下 PixInsight。

## 已知限制

- 只认 FITS（`.fit` / `.fits`），相机直接存的 RAW（CR2、NEF、ARW）和 XISF 格式的原始帧暂不支持。
- 校准帧库里只有 master 文件、没有原始帧时，不会被用上。
- 处理配方只有彩色相机的；黑白相机的数据能导入，但还不能按配方出图。
- 界面只有中文。
- 安装包没有数字签名：Windows 首次运行要点“更多信息 → 仍要运行”；macOS 要在“隐私与安全性”里点“仍要打开”。
- 运行任务时需要关掉 PixInsight 界面（同一时间只能有一个 PixInsight）。

## 隐私

- 所有处理都在本机进行，拍摄数据不会上传。
- 用云端 AI 时，只发送处理过程中的数值和预览小图；用本地模型则完全离线。
- API 密钥存在系统钥匙串（Windows 凭据管理器 / macOS 钥匙串），不写进任何文件。

## English summary

astroflow 0.2.0 is the first desktop release (Windows 10/11 x64; macOS Apple Silicon as an untested preview). It turns a night of one-shot-colour (OSC) FITS data into a finished image. It imports and organises the frames with matching darks, bias and flats, from any capture program or folder layout, DSLRs included. It stacks them with WBPP, then processes them in headless PixInsight with recipes for broadband nebulae, galaxies, multiband nebulae and comets. An optional AI assistant (any OpenAI-compatible model, local ones included) reviews each stage against top-rated AstroBin images of the same object and tunes the parameters.

Requirements: PixInsight 1.9+ with WBPP, the RC Astro BlurXTerminator, NoiseXTerminator and StarXTerminator, and the Gaia DR3/SP database for SPCC. The user interface is in Chinese only for now. The installers are not code-signed.
