# astroflow 0.3.0：黑白相机、窄带、多晚合并

这一版的重点是“各种情况都能处理”：黑白相机的 LRGB 和窄带、彩色相机的双窄带、几个晚上的数据合成一张、拍坏的帧挑出来。还有英文界面和自动更新。

## 下载

| 系统 | 文件 | 状态 |
|---|---|---|
| Windows 10 / 11（64 位） | `astroflow-0.3.0-setup.exe` | 已测试 |
| macOS（Apple 芯片） | `astroflow-0.3.0-arm64.dmg` | 预览版 |

安装方法和完整用法见[使用说明](https://github.com/mtang724/astroflow/blob/main/docs/user-guide.md)。从 0.2.x 升级直接安装新版即可，设置、密钥和数据都会保留。

**这一次要手动下载**：自动更新是这一版才加的，0.2.x 不会提示有新版本。装上 0.3.0 以后，Windows 版有新版本时会自动提示，点一下就能更新。

## 黑白相机

WBPP 按滤镜分别叠加以后，自动认出每个滤镜的主帧（L、R、G、B、Hα、OIII、SII，滤镜名写成 Lum、Red、Ha 7nm、Antlia SII 3nm 之类都认得），选对应的配方：

- **LRGB**：R、G、B 对齐到 L，裁掉对不上的边，各自去背景，合成彩色；L 单独做去卷积和降噪，再按彩色图的亮度合成进去。没拍 L 时用 R、G、B 的平均代替。
- **HOO 窄带**（Hα + OIII）：合成红 + 蓝配色，SPCC 用窄带模式校色；拍了 R、G、B 的话，星点换成它们的（窄带星点只有红、蓝、白）。
- **SHO 哈勃色**（SII + Hα + OIII）：只做色彩平衡（伪彩色不做 SPCC），用颜色蒙版调出金 + 蓝，星点颜色由三条谱线还原。

## 彩色相机 + 窄带滤镜

- **Hα + OIII 双窄带 / 多波段**（L-eXtreme、ALP-T、Antlia 四通道等）：配方按教程重做，SPCC 窄带模式、OIII 调蓝、背景配平。
- **两套双窄带合成 SHO**：概览里“这一晚的滤镜”新增 **S+O 双窄带**。一些晚上用 Hα + OIII、另一些晚上用 SII + OIII，合并叠加时两套各叠一张，再合成哈勃色。

## 几个晚上的数据合成一张

同一个目标拍了好几晚，概览里勾选要合并的晚上，点“合并叠加”：每晚用自己的平场校准，然后一起配准、叠加。合并的目标里是指向原文件的链接，不多占空间；之后拍了新的一晚，点“更新合并”就行。

## 检查单帧

叠加前看看每一帧：缩略图、星点数、星点大小、背景亮度，以及整晚的走势。被云、风、跑焦、月光或天亮影响的帧会标出来，一键排除（移到 `Excluded`，随时能恢复）。只和同一滤镜、同一曝光的帧比，黑白相机的 L 帧不会因为天生更亮被误标。

## 其他新功能

- **相机 RAW**：单反、微单的 CR2、CR3、NEF、ARW、DNG、RAF 等直接导入。
- **全部处理**：把还没出图的目标排队，一个接一个叠加、出图，后台跑完弹系统通知。
- **我的风格**：调好的参数存成风格，套用到同类目标。
- **分享图**：裁成 3:4、16:9 等比例，可加拍摄信息和署名。
- **磁盘空间和归档**：看每个目标占多少空间，一键删掉能再生成的中间文件；处理完的目标一键归档到 `Processed`。
- **English 界面**：设置 → 常规 → 界面语言（默认跟随系统），AI 助手也用同一种语言回答。
- **自动更新**：启动时检查新版本（可以在设置里关掉）。Windows 版点“下载新版本”，下完“重启并安装”，或者下次关闭时自动装好；macOS 预览版会打开下载页。

## 修复和改进

- **NINA 拍的数据、路径里有中文**：以前 WBPP 会什么都叠不出来（NINA 文件名里有 ℃，PixInsight 的命令行接不了这些字符），现在可以直接用：叠加时自动用英文名的临时链接，叠完把结果搬回来，原文件不改。
- **同一个目标几晚的名字写法不同**（`M 42` 和 `m42`）不再被分成两个目标。
- **导入时检查平场亮度**：太暗或接近饱和会提醒。
- **WBPP 设置**按教程第 6 期：PSF Signal 加权，不做 Local Normalization。
- **M42 这类亮核心**不再被拉成一片白：自动加 HDR，其他目标不受影响。

## English summary

astroflow 0.3.0 handles far more kinds of data:

- **Mono cameras:** LRGB, plus narrowband HOO (with broadband stars when R/G/B were shot) and SHO in the Hubble palette.
- **Colour cameras with narrowband filters:** Hα + OIII dual-band filters, and the two dual-band filter sets (Hα + OIII and SII + OIII) combined into SHO.
- **Several nights stacked into one:** each night is calibrated with its own flats.
- **Frame check:** per-frame star count, star size and background, compared within each filter.

Also new:

- Camera RAW import.
- "Process all" with a system notification.
- Saved styles.
- Share pictures.
- Disk space and one-click archiving.
- An English interface.
- Automatic updates: Windows installs them, the macOS preview opens the download page.

Fixes:

- Frames with non-ASCII characters in their paths now stack. NINA puts ℃ in its file names, and Chinese folder names had the same problem.
- The same object written differently on two nights is now one target.
- Flats far from half of full scale are flagged.
- WBPP uses PSF Signal weighting without local normalization.
- A burnt-out core such as M42's gets HDR.

0.2.x does not check for updates, so download 0.3.0 by hand once. Later versions arrive automatically on Windows.

The recipes follow the Bilibili series 《PixInsight 进阶教程》 by 氪化金, episodes 1–6.
