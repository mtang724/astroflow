# astroflow 0.2.1：检查运行环境

这一版帮第一次用的人把环境装齐：缺什么、怎么装，一目了然。

## 下载

| 系统 | 文件 | 状态 |
|---|---|---|
| Windows 10 / 11（64 位） | `astroflow-0.2.1-setup.exe` | 已测试 |
| macOS（Apple 芯片） | `astroflow-0.2.1-arm64.dmg` | 预览版 |

安装方法和完整用法见[使用说明](https://github.com/mtang724/astroflow/blob/main/docs/user-guide.md)。从 0.2.0 升级直接安装新版即可，设置、密钥和数据都会保留。

## 新功能：检查运行环境

第一次打开时，如果这台电脑还缺东西，会自动弹出“检查运行环境”，逐项检查：

- **PixInsight**：是否安装、版本是否 1.9 或更新。装在常见位置的会自动找到，一键填好路径。
- **PixInsight 脚本**：WBPP 和 ImageSolver 是否在。
- **RC Astro 插件**：BlurXTerminator、NoiseXTerminator、StarXTerminator 是否安装并激活。
- **Gaia DR3/SP 数据库**：SPCC 色彩校准要用的数据库有没有配置、文件还在不在。
- **数据根目录**：不存在时可以一键创建。
- **任务临时目录**：路径里有空格或中文时提示换一个。
- **AI 模型**（可选）：有没有 API 密钥。

缺的项目都附有安装步骤、下载链接，以及能直接点的按钮（使用找到的路径、创建文件夹、选择文件夹、打开设置）。从 PixInsight 装好东西切回来，会自动重新检查。

还缺必需组件时，顶部栏会显示“缺少 N 项组件”；也可以在 设置 → 常规 里打开。命令行版：`python -m astroflow doctor`。

只读检查，不会启动 PixInsight；许可证只检查有没有，内容不会被读出或上传。

## 其他改进

- **启动失败时说清楚原因**：从源码运行时找不到 Python 或缺少 Python 包，会提示怎么解决，并给出日志位置，不再直接报错退出。
- **macOS**：选 PixInsight 程序时选到 `PixInsight.app` 或安装文件夹也能认出来。
- **安装包信息**里写明了版权。

## English summary

astroflow 0.2.1 adds a setup check. On first launch, if anything is missing, a dialog lists PixInsight (1.9+), its WBPP and ImageSolver scripts, the RC Astro tools (installed and activated), the Gaia DR3/SP database for SPCC, the data folder, the job folder and the optional AI provider. Each missing item comes with install steps, download links and one-click fixes: use the detected path, create the folder, pick a folder, or open Settings. The same report is available from the command line with `python -m astroflow doctor`. The check is read-only, never starts PixInsight, and never reads out license contents. When the backend cannot start from a source checkout, the app now explains why (no Python, missing package) and shows where the log is.
