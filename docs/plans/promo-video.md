# 宣传与教程视频策划

> 状态：计划，之后再做。开拍前先把“要先拍板的事”定下来，再把“开拍前的准备”做完。

## 一句话定位

**“拍完一晚，剩下的交给它：从拍摄数据到成品图，整理、叠加、后期、AI 调参，一个桌面应用搞定。”**

要讲清楚：astroflow 不是 PixInsight 的替代品，而是替你驱动 PixInsight。观众会更信任。

## 要先拍板的事

| # | 问题 | 选项 / 建议 |
|---|---|---|
| 1 | 怎么发布 | 开源（GitHub 公开仓库 + 许可证），还是先小范围内测。视频结尾要给下载地址，必须先定 |
| 2 | 平台和语言 | B站（长视频主阵地）；小红书 / 抖音（竖屏短片）；YouTube（英文字幕版）。界面目前只有中文，要面向海外得先做英文界面 |

| 5 | 别人的作品 | AstroBin 高赞作品的原图不放进视频（版权），只展示数值对比，或者打码 |

## 卖点（按说服力排序）

主打深空摄影后期，演示一个星云（M8）和一个星系（M101），同一晚拍的。

1. **出图快**：一晚的原始叠加，到成品。后期六个阶段，每个目标 3–7 分钟（不含 WBPP 叠加）。已经实测过发射星云（M8、NGC 6334、IC 1805）、行星状星云（NGC 7293）、星系（M101）。
2. **导入不用操心**：ASIAIR、NINA、单反都行，自动配好校准帧，缺什么一眼看到，补拍的暗场会自动补上。
3. **星云、星系配方自动选**：星系会绕开本体去背景、核心做 HDR，不用自己记哪种目标该怎么处理。
4. **想改就改**：每一步的参数都能调，改完只重跑那一个阶段。
5. **AI 助手**：问一句“和高赞作品比差在哪”，它看图、对比数值、调参、写报告。可以用 DeepSeek、OpenAI，也可以用本地模型。
6. **数据安全**：原始数据留在本机。用云端 AI 时只发送预览小图和数值；用本地模型则完全离线。

## 长视频分镜（约 10 分半）

逐镜头的旁白和剪辑见 [promo-video-script.md](promo-video-script.md)，这里是大纲：

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:25 | M8 原始叠加（灰绿、带梯度）→ 硬切成品 → 成品快切 | “一晚数据，到成品图” |
| 0:25–1:25 | 传统流程的痛点（整理文件、WBPP、十几步 PixInsight） | 它是什么、适合谁；前提是有 PixInsight 和 RC Astro |
| 1:25–2:40 | 安装、检查运行环境、选 AI 服务商 | 缺什么都写了怎么装；密钥存在系统钥匙串里 |
| 2:40–3:55 | 选 ASIAIR 文件夹 → 导入计划 → 导入 | 单反也行；补拍的暗场会自动补上 |
| 3:55–5:30 | 星云 M8：WBPP → 六个阶段 → 成品 | 加速播放，角标注明真实耗时 |
| 5:30–6:30 | 改饱和度 → 从这一阶段重跑 → 前后对比 | 按自己的口味来 |
| 6:30–7:30 | 星系 M101：排队处理，星系配方的不同（绕开本体去背景、核心 HDR） | 配方按目标类型自动选 |
| 7:30–9:30 | AI 助手看 M101、对照高赞作品、调参、写报告 | 判断交给 AI，每一步有依据 |
| 9:30–10:30 | 总结、需要什么、下载地址、致谢 | 号召试用和反馈 |

## 短片结构（60–90 秒）

- **0–3 秒**：钩子，M8 原始叠加和成品的前后对比。
- **3–40 秒**：三个 10 秒镜头：导入自动配校准帧、一键出图（加速）、一句话让 AI 调色。
- **40–70 秒**：成品墙。
- **70–90 秒**：下载地址，加一句“需要 PixInsight”。
- **竖屏版**：剪辑时放大局部，字幕要大。

## 画面里不能出现的

- API 密钥、`.env` 文件；
- FITS 头里的拍摄坐标（SITELAT / SITELONG），会暴露你家位置；
- 别人的作品原图、教程视频画面；
- 带用户名的路径：用一个单独的演示数据目录（比如 `D:\AstroDemo`）。

## 素材与制作

- **录屏**：OBS，2560×1440、60 帧，开鼠标高亮。按分镜分段录，每段录两遍。
- **演示目标**：M8（星云）和 M101（星系），都是 2026May17 那晚拍的。开场的成品快切另外加 IC 1805、NGC 6334、NGC 7293；M51、NGC 246 在视场里太小，不放。再从 M8 各阶段预览图做一段“线性数据 → 成品”的演变动画。
- **可直接用的截图**：`docs/images/`（概览、导入、处理流程、对比、AI 助手、设置）。
- **剪辑**：剪映或 DaVinci Resolve；中文字幕，YouTube 版加英文字幕；音乐用免版权曲库。
- **封面**：成品左右对比，配大字“一晚数据 → 成品图”。

## 时间安排（约 3 周）

- **第 1 周**：定发布方式，真跑验收并修 bug，准备演示数据，写旁白稿。
- **第 2 周**：分段录屏，配音，剪长视频。
- **第 3 周**：剪短片（横竖两版）、字幕、封面。B站首发，再发小红书 / 抖音 / YouTube；同时发 GitHub Release，在寻星客、Cloudy Nights 发帖。

**看效果**：播放量和完播率、下载量、反馈数量。第一周的反馈整理成下一版的改进清单。
