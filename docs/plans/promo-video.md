# 宣传与教程视频策划

> 状态：计划，之后再做。开拍前先把“要先拍板的事”定下来，再把“开拍前的准备”做完。

## 一句话定位

**“拍完一晚，剩下的交给它：从拍摄数据到成品图，整理、叠加、后期、AI 调参，一个桌面应用搞定。”**

要讲清楚：astroflow 不是 PixInsight 的替代品，而是替你驱动 PixInsight。观众会更信任。

| # | 问题 | 选项 / 建议 |
|---|---|---|
| 1 | 怎么发布 | 开源（GitHub 公开仓库 + 许可证），还是先小范围内测。视频结尾要给下载地址，必须先定 |

## 做一长一短两支，素材一次录完

| | 宣传短片 | 完整教程 |
|---|---|---|
| 时长 | 60–90 秒 | 10–12 分钟，分章节 |
| 平台 | 抖音 / 小红书竖屏；B站 / YouTube 横屏 | B站 / YouTube |
| 目的 | 让人想试 | 让人会用 |

## 卖点（按说服力排序）

1. **出图快**：已经实测 8 个目标，包括发射星云（M8、NGC 6334、IC 1805）、行星状星云（NGC 246、NGC 7293）、星系（M101、M51）、彗星（C/2025 R3）。后期六个阶段，每个目标 3–7 分钟出成品（不含 WBPP 叠加）。
2. **导入不用操心**：ASIAIR、NINA、单反都行，自动配好校准帧，缺什么一眼看到，补拍的暗场会自动补上。
3. **想改就改**：每一步的参数都能调，改完只重跑那一个阶段。
4. **AI 助手**：说一句“背景再暗一点”，它看图、和高赞作品对比、调参、写报告。可以用 DeepSeek、OpenAI，也可以用本地模型。
5. **难例**：穿云拍的 C/2025 R3，只有 5 帧、曝光长短不一，云和卫星轨迹自动剔除。
6. **数据安全**：原始数据留在本机。用云端 AI 时只发送预览小图和数值；用本地模型则完全离线。

## 长视频分镜（约 10 分钟）

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:20 | 存储卡拖进应用 → 加速 → 8 张成品拼贴 | “一晚数据，到成品图” |
| 0:20–1:00 | 传统流程的痛点（整理文件、WBPP、十几步 PixInsight） | 它是什么、适合谁；前提是有 PixInsight 和 RC Astro |
| 1:00–2:00 | 安装、首次设置（数据目录、PixInsight 路径、选 AI 服务商） | 密钥存在系统钥匙串里 |
| 2:00–3:30 | 选 ASIAIR 文件夹 → 导入计划（随数据 / 校准帧库 / 缺少）→ 导入 | 单反也行（M51 是单反拍的）；补拍的暗场会自动补上 |
| 3:30–5:30 | 一键 WBPP → 处理流程页六个阶段依次运行 → 成品 | 加速播放，角标注明真实耗时 |
| 5:30–7:00 | 改饱和度 → 只重跑一个阶段 → 滑块前后对比 | 按自己的口味来 |
| 7:00–9:00 | 对 AI 说“星云颜色更明显一点” → 看它查看、看图、对比、调参 → 报告 | 判断交给 AI，每一步有依据 |
| 9:00–10:00 | 彗星：WBPP → 彗星叠加 → 权重图（黑色是被剔除的云）→ 成品 | 云多、帧少也能出图 |
| 10:00–10:40 | 下载地址、需要什么、反馈渠道、接下来做什么 | 号召试用和反馈 |

## 短片结构（60–90 秒）

- **0–3 秒**：钩子，用彗星穿云的前后对比。
- **3–40 秒**：三个 10 秒镜头：导入自动配校准帧、一键出图（加速）、一句话让 AI 调色。
- **40–70 秒**：成品墙。
- **70–90 秒**：下载地址，加一句“需要 PixInsight”。
- **竖屏版**：剪辑时放大局部，字幕要大。

## 画面里不能出现的

- API 密钥、`.env` 文件；
- FITS 头里的拍摄坐标（SITELAT / SITELONG），会暴露你家位置；
- 别人的作品原图、教程视频画面；
- 带用户名的路径：用一个单独的演示数据目录（比如 `D:\AstroDemo`）。

## 素材与制作

- **录屏**：OBS，2560×1440、60 帧，开鼠标高亮。按分镜分段录，每段录两遍。
- **演示目标**：IC 1805（星云）、M101（星系）、NGC 7293（行星状星云）、C/2025 R3（彗星）。再从各阶段预览图做一段“线性数据 → 成品”的演变动画。
- **可直接用的截图**：`docs/images/`（概览、导入、处理流程、对比、AI 助手、设置）。
- **剪辑**：剪映或 DaVinci Resolve；中文字幕，YouTube 版加英文字幕；音乐用免版权曲库。
- **封面**：成品左右对比，配大字“一晚数据 → 成品图”。
